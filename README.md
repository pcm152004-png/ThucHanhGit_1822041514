## 2. Mục Tiêu Bài Tập
1. Thực hành khởi tạo và quản lý mã nguồn bằng **Git** trên máy tính cá nhân (Local Repository).
2. Kết nối và đồng bộ dự án với **GitHub** (Remote Repository).
3. Nắm vững thao tác quản lý phân nhánh (**Branching**): tạo nhánh `feature/them-giao-dien`, thực hiện commit độc lập.
4. Nắm vững quy trình gộp nhánh (**Merging**): gộp các thay đổi từ nhánh tính năng vào nhánh chính (`main`).
5. Xuất báo cáo tổng kết quá trình thực hiện dưới dạng tài liệu hoàn chỉnh.
